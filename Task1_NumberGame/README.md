# Task 1 - Number Guessing Game

## Description
A console-based Number Guessing Game built in Java as part of the CodSoft Java Development Internship. The program generates a random number between 1 and 100, and the user has to guess it within a limited number of attempts. The game provides feedback (too high / too low / correct) after each guess and keeps track of the score across multiple rounds.

## Features
- Generates a random number between 1 and 100
- Gives real-time feedback on each guess (too high, too low, or correct)
- Limits the number of attempts per round (5 attempts)
- Score system based on how quickly the number is guessed
- Option to play multiple rounds
- Displays total score at the end

## Tech Stack
- Java (Core Java, OOP concepts)
- java.util.Random for number generation
- java.util.Scanner for user input

## How to Run

1. Clone this repository
```bash
   git clone https://github.com/sarthakthakur1405/CODSOFT-_-TASKSNO.git
```
2. Navigate to the Task 1 folder
```bash
   cd Task1_NumberGame
```
3. Compile the program
```bash
   javac NumberGame.java
```
4. Run the program
```bash
   java NumberGame
```
