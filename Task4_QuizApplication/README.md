# Task 4 - Quiz Application with Timer

## Description
A console-based Quiz Application built in Java as part of the CodSoft Java Development Internship. The application presents multiple-choice questions one at a time, with a time limit for each question. It tracks the user's score based on correct answers and displays a final result summary at the end.

## Features
- Stores quiz questions along with multiple-choice options and correct answers
- Implements a timer (10 seconds) for each question
- Displays one question at a time with multiple-choice options
- Allows users to submit an answer within the given time limit
- Automatically moves to the next question if time runs out
- Calculates and tracks the user's score
- Displays a final score and a summary of correct/incorrect/unanswered questions

## Tech Stack
- Java (Core Java, OOP concepts)
- java.util.concurrent (ExecutorService, Future) for implementing the timer
- java.util.Scanner for user input

## How to Run

1. Clone this repository
```bash
   git clone https://github.com/sarthakthakur1405/CODSOFT-_-TASKSNO.git
```
2. Navigate to the Task 4 folder
```bash
   cd Task4_QuizApplication
```
3. Compile the program
```bash
   javac QuizApplication.java
```
4. Run the program
```bash
   java QuizApplication
```
