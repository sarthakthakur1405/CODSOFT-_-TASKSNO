# Task 5 - Student Course Registration System

## Description
A console-based Student Course Registration System built in Java as part of the CodSoft Java Development Internship. The application manages course and student data, allowing students to view available courses, register for courses within available capacity, and drop courses they are currently enrolled in.

## Features
- Stores course information including course code, title, description, capacity, and schedule
- Stores student information including student ID, name, and registered courses
- Displays a list of available courses along with available slots
- Allows students to register for a course, with capacity validation
- Prevents duplicate registration for the same course
- Allows students to drop a course they are registered for
- Displays all courses a student is currently registered in

## Tech Stack
- Java (Core Java, OOP concepts)
- java.util.ArrayList and List for managing course and student data
- java.util.Scanner for user input
