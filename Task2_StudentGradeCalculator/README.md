# Task 2 - Student Grade Calculator

## Description
A console-based Student Grade Calculator built in Java as part of the CodSoft Java Development Internship. The program takes marks obtained by a student in multiple subjects, calculates the total marks and average percentage, and assigns a grade based on the average percentage achieved.

## Features
- Accepts marks (out of 100) for multiple subjects
- Validates input to ensure marks are between 0 and 100
- Calculates total marks obtained
- Calculates average percentage
- Assigns a grade based on average percentage
- Displays total marks, average percentage, and final grade

## Grading Criteria
| Average Percentage | Grade |
| 90 and above | A+ |
| 80 - 89 | A |
| 70 - 79 | B |
| 60 - 69 | C |
| 50 - 59 | D |
| Below 50 | F |

## Tech Stack
- Java (Core Java, OOP concepts)
- java.util.Scanner for user input

## How to Run

1. Clone this repository
```bash
   git clone https://github.com/sarthakthakur1405/CODSOFT-_-TASKSNO.git
```
2. Navigate to the Task 2 folder
```bash
   cd Task2_StudentGradeCalculator
```
3. Compile the program
```bash
   javac GradeCalculator.java
```
4. Run the program
```bash
   java GradeCalculator
```
